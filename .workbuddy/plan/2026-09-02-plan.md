## 变更二:营收/毛利人民币(scripts/generate_dashboard.py)

  ```python
  NGN_CNY_RATE = 0.0050  # 1 NGN ≈ 0.0050 CNY (2026-09-02 参考价,可调)
  def fmt_rmb(ngn):
      cny = ngn * NGN_CNY_RATE
      if abs(cny) >= 1e8: return f"≈¥{cny/1e8:.2f}亿"
      if abs(cny) >= 1e4: return f"≈¥{cny/1e4:.1f}万"
      return f"≈¥{cny:.0f}"
  ```
