## 使用方式

- 双击任意 .html 文件即可在浏览器中打开
- 每个文件包含4个标签页：数据看板 / 问题汇总 / 价格分析 / 历史趋势
- 6—9月历史文件沿用原版；10月文件为完整收官看板的原样快照，图表脚本需要联网加载，离线时可查阅已保存的表格和文字。

## 说明

- 数据来源：当月每日销售数据 Excel + 目标文件 + 价格表 + 库存 + 成本
- 生成工具：scripts/generate_dashboard.py + scripts/process_data.py
- 当月看板会持续更新，月底最终版存档至此文件夹
- 整月文件归档后保持只读，不再覆盖或改动。新月份新建独立看板，不使用新月份数据重写旧月份存档。
- 10月版本包含门店分析、品牌&型号分析、库存、人效和经营驾驶舱，销量范围为零售智能机及平板，排除COMMERCE/B2B；库存与价格为10月28日版本，成本为10月26日版本。
